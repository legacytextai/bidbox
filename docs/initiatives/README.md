# Initiatives

This folder holds BidBox initiative documentation (initiative documents, implementation plans, task lists).

**Organization:**

- **Root (`docs/initiatives/`)** — active, planned, partially implemented, or otherwise outstanding initiatives. If any major part of an initiative is still open, its whole document set lives here.
- **`completed/`** — initiatives that are fully implemented, production-validated, and formally closed (or explicitly superseded with no outstanding work). Move a document set here only after implementation **and** validation are complete; a written proposal, passing proof of concept, or partial rollout does not qualify.

Related document sets (initiative doc + implementation plan + task list) move together — never split one initiative across both locations.
