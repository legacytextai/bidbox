# Bug Prompt Training Template

Can you use the following format and your prior knowledge in this chat
and build a debugging prompt template for me?

**For future issues, please build prompts to fixing them using the
following template, please memorize this for future use!!!! This is
extremely important!!!**

## **Bug Description**

*Example: "Name field in signup form is not accepting any input."*

## **Current Behavior**

-   *(List symptoms or observable behaviors, e.g. "Name field doesn't
    respond to keyboard input.")*
-   *(Describe console errors or lack thereof, e.g. "No visible errors
    in console.")*
-   *(Mention any effect on data, e.g. "Form submission includes empty
    name value.")*

## **Expected Behavior**

-   *(State what should happen, e.g. "Name field should accept text
    input.")*
-   *(Mention correct data handling, e.g. "Input should be reflected in
    form state.")*
-   *(Describe expected outcome, e.g. "Form should submit with entered
    name.")*

## **Steps to Reproduce**

1.  *(Step-by-step instructions, e.g. "Navigate to /auth.")*
2.  *(Second step, e.g. "Click on name input field.")*
3.  *(Third step, e.g. "Try typing any characters.")*

## **Environment**

-   *(List relevant routes, components, frameworks, e.g. "Route: /auth,"
    "Component: SimpleAuthForm.")*
-   *(Mention libraries or versions, e.g. "Form Library: React Hook
    Form.")*
-   *(Include environment details, e.g. "Authentication: Supabase.")*

## **Additional Context**

-   *(Any extra info about setup or dependencies, e.g. "Using React Hook
    Form's register.")*
-   *(Note relevant context, e.g. "Form validation with Zod.")*
-   *(Mention relationships to other parts of the system, e.g. "Part of
    AuthProvider context.")*

**PLEASE CONFIRM THAT YOU UNDERSTAND AND ASK ME TO PASTE THE ISSUE OR
ERROR CODE DESCRIPTION.**
